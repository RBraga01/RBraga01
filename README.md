## Smart glasses

**[Agent HUD](https://github.com/RBraga01/agent-hud)** — A quiet interface for Raven Prism smart glasses that shows when a coding agent needs a decision, without demanding constant attention.

**[DOOMed Prism](https://github.com/RBraga01/DOOMed-Prism)** — An experimental DOOM port for Raven Prism smart glasses, built around a Qt-composited shared-memory framebuffer and gaze-driven controls. The Raven team compiled and ran it on actual Prism hardware directly from the repository.

These are experiments in wearable interfaces, unconventional input, and what becomes possible when software is designed around smart glasses rather than adapted from a phone.
